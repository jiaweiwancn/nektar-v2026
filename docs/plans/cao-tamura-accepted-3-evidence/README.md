# CT-Accepted-3 evidence

Read the [report](../cao-tamura-accepted-3.md) and [decision](decision.json)
together. Diagnostic completion does not imply physical, spatial, precursor or
benchmark admission. A95 P3/P1 and P4/P2 and E94E95 P3/P1 complete T=.2;
A93 completes .02 and rejects later on full-tensor covariance. Evolved local
A95 spatial sensitivity remains unresolved.

- `contract.json`, `spatial-interpretation-contract.json`, and
  `profiling-contract.json` record the predeclared scope and criteria.
- `*-initial.json`, `*-T*.json` contain complete case, coverage and primitive
  classifications; `*-derived.json` recompute the required gates using actual
  native/XML/state/history/budget bindings. Both timesteps are present.
- `equal-time-comparisons.json` contains all selected common physical times,
  initial projection and subsequent evolution, separate global and local
  uncertainty statuses, common-grid native sides and witness data. No formal
  convergence order is inferred.
- `physical-summary.json` and `accepted-state-extrema.json` supplement the
  complete endpoint receipts with all accepted native audit times, component
  minima/maxima and final audits. Rejected stages are in `failure-witnesses.json`.
- `failure-witnesses.json` independently reproduces both A93 tensors and native
  single-attempt rejection/rollback. Failed high-quadrature packets are hashed
  external artifacts; they are not converted to passing budget primitives.
- `degree-pressure-and-coverage-controls.json` and
  `complete-budget-negative-controls.json` contain independent P4/P2 pressure,
  manufactured p=x^2 rough-volume action, traction offsets, coverage negatives,
  command failure propagation and all six unchanged CT2 positive budgets.
- `accepted-costs.json`, `timing-*.json` separate ordinary accepted-run cost,
  initialization, observation export and intrusive detailed timing. Profiled
  accepted coefficients and native histories agree bitwise with the pinned
  primary runtime. Detailed telemetry overhead is explicitly measured.
- `source-scope.json`, `final-provenance.json`, `export-provenance.json`,
  `native-artifact-hashes.json`, `requests-and-seals.json` and per-execution
  loaded-image hashes identify the actual source, runtimes, functions, consumed
  boundaries, configurations, histories and heavy Linux artifacts.
- `frozen-functions-by-hash.json` stores repeated physical function maps once;
  `functions_ref_sha256` in another body references that map without changing
  its mathematical content.
- `fresh-resources.json` is the compact-export snapshot.
  `completed-family-resources.json` includes every earlier completed family,
  including failed collectors. Its finalizer was still active when it wrote
  that file; `finalization-resource-final.json`, `finalization-execution.json`
  and `finalization-*-highwater.jsonl` close that final family after exit.
  Observed aggregate/project peaks are 22/13, against limits 72/16. No old
  resource receipt is overwritten.
